# API-v2 design

This directory will contain the proposed public surface and its rationale after
the comparative review prepass.

The expected subjects are:

- naming and `mv` namespace conventions;
- backend policy architecture;
- core compute and packed storage types;
- points, directions, normals, rotations, and transforms;
- geometric primitives and spatial queries;
- frustum and culling facilities;
- invariants, errors, and checked/unchecked construction;
- public and internal header organization.

Design files are proposals until accepted at the design checkpoint.
